# Security Policy

## Scope

This repository publishes the static website at `https://aridiosilva.com/`, including the public pages `index.html` and `sgaeia.html`.

The currently supported version is the content published from the `main` branch.

## Reporting a vulnerability

Please report suspected security vulnerabilities through GitHub's **Private vulnerability reporting** feature for this repository:

`https://github.com/aridiosilva/aridiosilva.github.io/security/advisories/new`

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or commit comment before it has been assessed and, when necessary, mitigated.

Include, when available:

- the affected page, file, or URL;
- a clear description of the behavior and potential impact;
- reproducible steps or a minimal proof of concept;
- relevant browser, operating system, and date/time information;
- supporting evidence with credentials, tokens, personal data, and unrelated sensitive information removed;
- a proposed mitigation, if known.

## Coordinated disclosure

Reports will be assessed privately. Public disclosure should occur only after the issue has been investigated and an appropriate mitigation or disclosure plan has been agreed upon.

## Non-security matters

Content corrections, broken links, accessibility suggestions, and general site feedback may be submitted through the repository's public issue tracker.
